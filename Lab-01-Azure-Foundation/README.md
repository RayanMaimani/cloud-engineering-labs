
# Lab 01 - Azure Foundation

##  Goal

Build the foundation of an Azure lab environment for future cloud projects.

---

##  Concept

This lab focused on preparing the Azure environment before deploying workloads.

The following resources were created:

- Azure Subscription
- Resource Group
- Virtual Network
- Subnet

---

##  Resources Created

- Resource Group: RG-LAB-01
- Virtual Network: network-lab
- Address Space: 10.0.0.0/16
- Subnet: subnet-managment-lab
- Subnet Prefix: 10.0.1.0/24

---

##  What I Learned

- Azure Resource Groups
- Virtual Networks
- Subnets
- Azure resource organization

---

##  Real World Usage

Resource Groups help organize cloud resources.

Virtual Networks provide isolated networking for Azure workloads.

Subnets separate workloads into logical network segments.

This forms the foundation for Virtual Machines, VPNs, Load Balancers, Firewalls, and other Azure services.
